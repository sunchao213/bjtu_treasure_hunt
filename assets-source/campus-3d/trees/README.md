# 校园像素乔木

- 原图：用户于 2026-11-22 提供的「复古像素风繁茂大树.png」，保留为 `user-tree-source.png`（1254×1254 RGBA）。用户已要求加工并接入三维地图；生成工具及其条款未在会话中提供。
- 透明处理：原图已有真实 alpha，不重新抠图；清理 alpha 小于 24 的外围碎点，裁去空白，缩到约 496×496，整理为二值透明边缘，再放入 512×512 透明画布。树根锚点固定在 `(256,504)`。
- 重建输出：运行 `python scripts/prepare_campus_tree.py`（Pillow、NumPy），写入 `public/assets/environment/campus-trees/tree.png`，约 239 KiB。明／暗／草地底色和边缘四倍放大检查见 `artifacts/campus-3d/trees/`。
- 运行时：`src/campus-3d/tree-view.ts` 使用单个 InstancedMesh，在原来的 198 个校园树木位置绘制；南门和思源楼样板也复用相同素材。树木大小轻微变化，以树根贴地，不修改布局及树干碰撞。
- 镜头：采用 2.5D 面片，随镜头朝向变化，保持像素轮廓可读；单张图片不包含真实的侧面或背面。法线固定朝上，使昼夜环境、路灯与手电照明不会因树图转向而突然变亮。
- 遮挡：透明部分不写深度，实心树叶按三维深度遮挡；挡住角色的树冠逐渐使用屏幕点阵淡出。原低模树仅继续提供稳定阴影，不再绘制颜色或深度。灌木、长椅和其他共用树皮材质的物体仍保留。
- 性能：像素树共享一张贴图和一次实例绘制；同一检查镜头下，白昼绘制次数由 59 变为 60，夜间由 63 变为 64。这是当前场景采样，不代表所有设备性能。
- 验证：浏览器覆盖白昼／夜间、四个环绕方向、高俯角、总览、角色后方树冠淡出、两个样板区加载和正常开局移动。单元测试检查镜头旋转时锚点固定、树图朝向及遮挡淡出／恢复。
