# 校园像素沥青

- 原图：用户于 2026-11-22 提供的「深蓝灰像素沥青纹理.png」，保留为 `user-asphalt-source.png`（1254×1254）。
- 用户已授权加工并接入三维道路；生成工具及其条款未在本次会话提供。
- 处理：`python scripts/prepare_campus_asphalt.py`，依赖 Pillow、NumPy，并复用草地脚本的周期分量修复与边缘匹配。面积缩采样至 256×256，降低纹理对比，保持深蓝灰色调，不增加烘焙灯光。
- 输出：`public/assets/environment/campus-asphalt/asphalt-albedo.png`，RGB、不透明，四边对应像素差为零，约 83 KiB。
- 显示：世界 X/Z 投影，每 6 场景单位（192 逻辑单位）重复一次；放大最近邻，缩小使用 mipmap 和最多 8 倍各向异性过滤。哑光材质，继续响应白昼、路灯、夜间和手电照明。
- 范围：连续校园模型的 `district_asphalt`，包括主路、斜向连接路、停车区和旗杆前沥青区域；南门／思源楼样板的程序道路复用同一贴图。路缘、人行步道、车道及停车标线仍使用原材质。
- 检查：`artifacts/campus-3d/asphalt/` 保存修整后九宫格、前后白昼／夜间近景与总览，以及浏览器检查报告。近景使用独立检查镜头，不修改游戏默认镜头。
