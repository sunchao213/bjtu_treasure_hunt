# E 质量与发布核对

## 需求到设计到测试覆盖

| 编号  | 需求/规则                | 设计依据                                 | 自动测试或人工核对           |
| ----- | ------------------------ | ---------------------------------------- | ---------------------------- |
| F1-01 | 2 秒持续搜索             | `SearchInteraction.progress/finish`      | 单测：完成阈值与未完成拒绝   |
| F1-02 | 松键/移动/受伤取消       | `WorldScene.clearInteractions`、伤害事件 | 单测：`cancel`；浏览器烟测   |
| F1-03 | 满包不吞物               | `finish` 只有插入成功才打开地点          | 单测：失败后可重试           |
| F1-04 | 搜索点去重               | `opened` 集合                            | 单测：重复 `begin` 拒绝      |
| F1-05 | 前置证据                 | `WorldScene.interact` 调查分支           | 浏览器核对：无手记不能搜羽毛 |
| F1-06 | 本局物品价值与带入物区分 | `ItemOrigin` 与 `raidId`                 | 价值/结算集成测试            |

## 发布核对表

- [ ] `npm.cmd ci` 后 `npm.cmd run check` 通过。
- [ ] `npm.cmd run build` 生成 `dist/`，未包含存档或试用者信息。
- [ ] 开发服务器完成一次搜索取消、满包重试和重复搜索烟测。
- [ ] 生产预览隐藏开发伤害/死亡入口。
- [ ] GitHub Pages 部署后从公开网址打开地图，记录浏览器和教学机结果。
- [ ] 部署失败时保留上一份可运行构建，不把“构建成功”写成“已上线”。

当前仓库已具备构建与 CI 检查；真实浏览器、教学机和公开网址验证需在部署环境执行后回填。
