## 发布核对表

- [ ] `npm.cmd ci` 后 `npm.cmd run check` 通过。
- [ ] `npm.cmd run build` 生成 `dist/`，未包含存档或试用者信息。
- [ ] 开发服务器完成一次搜索取消、满包重试和重复搜索烟测。
- [ ] 生产预览隐藏开发伤害/死亡入口。
- [ ] GitHub Pages 部署后从公开网址打开地图，记录浏览器和教学机结果。
- [ ] 部署失败时保留上一份可运行构建，不把“构建成功”写成“已上线”。

当前仓库已具备构建与 CI 检查；真实浏览器、教学机和公开网址验证需在部署环境执行后回填。
