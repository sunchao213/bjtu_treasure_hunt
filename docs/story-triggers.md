# 正式校园剧情触发点

剧情使用本局新取得且仍携带的证据递进，旧局证据和带入物不会跳过前置。每章的第一处目标在地图上显示金色菱形；局内左上角显示目标、方位、距离及操作。走近当前目标会播放一次地点引入，阅读期间暂停，关闭后继续。场景中金色环表示可调查，灰蓝色表示缺少前置，绿色表示证据已取得。

| 章节   | 触发顺序                                 | 操作与结果                                                                                            |
| ------ | ---------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| 第一章 | 思源楼前手记宝箱 → 明湖石碑 → 南门       | 手电照亮宝箱，停住长按 E；携带本局手记，停住按 E 调查石碑取得羽毛；带齐证据并达到 100 价值后按 E 撤离 |
| 第二章 | 教学区公告栏 → 思源楼东侧记录侧门 → 南门 | 按 E 取得被涂改的校园地图；携带地图按 E 对照侧门取得钥匙；带齐证据撤离                                |
| 第三章 | 芳华园求助者 → 中心广场记录台 → 南门     | 靠近听见请求，停住长按 Q 安抚并取得护符；携带护符按 E 读取完整记录；带齐证据撤离                      |

明湖石碑使用用户提供的图片，原图保存在 `assets-source/story/minghu-stele-reference.png`，运行素材为 `public/assets/props/minghu-stele.png`。通过 `python scripts/prepare_minghu_stele.py` 重建透明背景。石碑脚点位于地图 `(2080, 290)`，即原位置前方偏右、明湖北端弯岸外的草地，避开明湖路。渲染和交互共用 `formal-campus.json` 中的脚点。石碑绕竖直轴面向镜头，保持底部贴地。

公告栏、记录侧门、记录台使用固定场景物件调查，不再同时生成同位置证据宝箱。已调查地点不能重复发放物品；丢弃证据后目标提示改为拾回，拾取保留原物品 ID 和本局来源。满包不消耗调查机会。芳华园遭遇中断或求助者被击倒后，可在求助点停住按 E 再次呼唤，然后重新安抚。

成功撤离后播放章末，关闭章末才保存永久章节解锁；失败仍沿用原有证据与结算规则。三章全部完成后，当前章节为空，后续开局进入自由探索：不再生成剧情证据、章节求助者或剧情地图标记，也不自动播放地点、证据和章末剧情；任务卡隐藏，行前目标只保留普通撤离目标。已完成章节仍可从剧情档案手动回看，重新登录或读档后同样生效。`tests/unit/formal-story.test.ts` 覆盖地点引入、石碑前置、满包重试、证据顺序、丢弃拾回、重复发放和安抚；浏览器流程 `tests/browser/game-flow-smoke.mjs` 通过真实输入验证三章与章节存档。
