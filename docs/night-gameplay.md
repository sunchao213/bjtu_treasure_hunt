# 夜间玩法与海淀主校区地图

更新日期：2026-10-10。

## 地图依据

本版本仅取小组提供的北京交通大学海淀主校区手绘地图部分。地图保留南门、西侧运动场、图书馆、明湖、思源楼、教学楼群、实验楼群及主要通路的相对位置。建筑轮廓、距离和道路宽度为适应二维游戏进行简化，不是校园测绘图或 1:1 复刻。

南门是出生点与唯一正式撤离点；西门、东门、东南门只作为地标。右上角概览同步显示地标、南门和玩家位置，不显示敌人位置。地图和碰撞数据集中在 `src/config/world-config.ts`。

## 游戏路线

1. 查看规则并开始探索；每局有 10 分钟、100 生命、6 格背包、满电手电、2 节备用电池和 2 根照明棒。
2. 在光照下靠近搜索点，停住并持续交互 2 秒完成搜刮。移动、松开按键或受伤会中断。
3. 躲避或击败巡逻敌人，拾取地面掉落；建筑会阻挡移动、攻击与视线。
4. 先在图书馆找到残缺手记，再到明湖石碑搜索异常羽毛；携带两件本局线索成功撤离可解锁章节。
5. 普通、稀有、史诗、传说物品价值分别为 10、25、60、150。只有本局搜得且仍携带的物品计入价值。
6. 携带价值达到 100 后回到南门，按 E 并在区域内保持 5 秒完成撤离。受伤、离开区域或价值不足会中断读条。

## 夜间照明与操作

| 操作                         | 电脑          | 触屏     |
| ---------------------------- | ------------- | -------- |
| 移动                         | WASD / 方向键 | 左侧摇杆 |
| 朝向                         | 鼠标指向      | 移动方向 |
| 搜索、拾取、抱抱、充电、撤离 | E             | 交互按钮 |
| 近身攻击                     | Space         | 攻击按钮 |
| 手电开关 / 换电池 / 放照明棒 | L / R / G     | 对应按钮 |

手电会持续耗电；照明棒持续 30 秒。靠近灯站并持续交互 2 秒可充满手电。规则弹窗打开时会暂停计时、敌人行动和照明消耗，并取消当前读条。

## 地图限制

建筑和湖面会影响移动与视线；搜索点以游戏地图标记为准。地图采用游戏化比例，仅供游戏使用，不能用于现实导航。原始手绘图只作为设计依据，不作为运行时背景图。

## 验收记录

执行 `npm.cmd run check` 应通过格式检查、ESLint、TypeScript、单元测试和生产构建。地图测试覆盖从南门到全部搜索点、灯站和敌人路点的可达性，并检查搜索点不落入建筑或湖面碰撞区。
