# 正式游戏接入南部三维校园

日期：2026-11-24（Asia/Shanghai）。本次只修改本地工作区并生成构建，未部署公网服务。

## 运行边界

正式入口 `/` 的单人与组队使用同一南部校园，默认夜间、近距离环绕镜头。保留大厅、背包、设置、任务、账号、仓库、图鉴和云存档。`campus-3d.html` 仍是独立试验页，正式入口不读取它的存档、网址参数、固定八宝箱规则或快捷键。

| 文件                                   | 职责                                                                           |
| -------------------------------------- | ------------------------------------------------------------------------------ |
| `src/game.ts`                          | 既有账号和界面服务，统一处理 Tab／Esc、面板、暂停和清理                        |
| `src/modules/world/formal-world.ts`    | 正式移动、搜索、掉落、章节、照明、战斗、队友插值与每局重置                     |
| `src/scenes/formal-world-scene.ts`     | 初始化、显式地图配置、绘制循环、尺寸调整、地图遮罩、上下文恢复与销毁           |
| `src/modules/world/formal-controls.ts` | 镜头相对输入、L／R／G、鼠标锁定与拖动、触屏镜头拖动；不处理 Tab／Esc           |
| `src/campus-3d/view.ts`                | GLB 校园、草地道路材质、像素树、动态宝箱、玩家与队友、调查物件、敌人及显示资源 |
| `src/config/formal-campus.json`        | 正式校园碰撞、出生位、撤离区、照明、任务与刷新区域                             |
| `server/CampusWorld.cs`                | 读取同一 JSON 的边界、建筑、水域与树干碰撞，分配十人出生位                     |

房间协议升级为 2，旧版本握手被拒绝。组队维持既有位置和地图共享能力；敌人、物资获取、战斗和撤离结算仍按玩家分别计算。不同章节共用种子时，普通宝箱坐标和普通物品一致，个人任务证据按章节替换。玩法继续用地面二维坐标，显示按 32 单位对应三维 1 单位转换。

## 操作与恢复

- Tab 开关原局内背包。Esc 无面板时打开设置，有背包时先关闭背包，有设置时关闭设置。原背包继续探索，设置／剧情／地图暂停。
- WASD／方向键相对当前镜头移动；E 搜索、拾取、调查、撤离；Q 安抚；空格攻击；L 手电；R 电池；G 照明棒。
- 点击地图捕获鼠标，Esc 释放与打开设置合并。打开面板会清空输入并释放鼠标，关闭后点击地图重新捕获。浏览器限制捕获时仍可拖动鼠标环绕。
- 文本输入获得焦点时清空移动和攻击，快捷键不触发游戏操作。快速按下再松开也会保留一次动作至下一帧。
- 手机沿用横屏与双摇杆；仅地图收到的触摸可拖动镜头，竖屏 CSS 旋转使用同一逆坐标转换。摇杆和操作按钮不转动镜头。
- 资源完成前禁止开局；失败显示重新加载，尚未带入装备。WebGL 上下文丢失会暂停、清空输入并显示设置，恢复后由玩家点击继续。
- 连续开局复用显示场景，刷新宝箱位置、已开状态、敌人、掉落和探索遮罩；页面退出和热更新销毁输入、绘制循环、监听器及 GPU 资源。

## 校园与章节

第一章固定手记位于思源楼前，明湖岸边有可辨认的石碑；第二章公告栏位于教学区，钥匙位于思源楼东侧；第三章搜寻区为芳华园和中心广场。保留原任务与物品 ID，去掉旧地图坐标依赖。所有搜索点经过连通地面与碰撞间距筛选。小地图、放大地图和大厅地图入口使用同一校园道路、水域与建筑布局，保留探索遮罩、玩家、队友、地标和撤离标记。

## 验证方式

运行生产构建、真实本地 HTTP／WebSocket 服务和 Chromium 无头浏览器。每个浏览器账号使用独立浏览器上下文，服务使用独立临时数据库，不写正式服务数据。浏览器测试通过 CDP 堆查询获取实际运行场景，没有增加生产调试入口。

剧情测试为节省长距离行走时间，会直接设置人物站位并关闭随机敌人，额外发放普通价值物以满足撤离门槛；证据仍通过正式 E 搜索／调查、剧情、背包、撤离和云端解锁流程取得。战斗测试把真实敌人安排在玩家附近，使用实际空格／Q 输入验证。地图连通、所有刷新点可达、碰撞与十个出生位另有自动化检查。因此浏览器结果属于功能集成回归，不代表全程徒步通关或真人游戏平衡测试。

本机 Node.js 为 26.13.0，仓库约定版本仍是 24.x；后端目标仍是 .NET 8，本机仅安装 .NET 10，运行时通过临时环境变量 `DOTNET_ROLL_FORWARD=Major` 验证，没有修改项目目标框架。手机使用 Chromium 触屏模拟，不代替真机性能与兼容性验收。
