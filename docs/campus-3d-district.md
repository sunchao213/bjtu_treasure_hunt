# 用户选定的南部校园连续区块

天佑会堂、明湖、图书馆已按新提供照片精修，球场退让道路，旗帜改为五星红旗，详见 [地标精修记录](campus-3d-landmarks.md)。

思源楼前大草坪与南门小广场已按重新读取的官网高清地图和全景校准，详见 [草坪与广场核对记录](campus-3d-forecourt.md)；旧版贯穿草坪的“南门主路”已移除，改走草坪两侧道路。

第九教学楼已按正面、侧面照片精修，模型与通行变化见 [第九教学楼说明](campus-3d-teaching9.md)。下方首版模型体积及性能属于历史记录，最新数据以 `asset-report.json` 为准。

入口：<http://localhost:5173/campus-3d.html?area=district>。默认使用以人物为中心的第三人称透视相机，右上角“返回人物／区域总览”可切回固定正交总览。

人物镜头下按住鼠标左键或右键拖动环绕，滚轮拉近拉远，R 重置。WASD／方向键按当前镜头方向移动；E 搜索和撤离，B 背包，Esc 暂停。镜头默认俯角 50°，可调范围 22°—75°，缩放范围 9—48 场景单位；地图边缘仍围绕人物，不把人物挤出中心。

镜头通过五条射线覆盖近裁剪面，遇到建筑或树木时立即收近、离开后平滑恢复，缩放设定独立保留。人物仍使用现有四方向精灵，会按相机方位选择朝向；鼠标地面指向在相机变化后重新投射。暂停、失焦和上下文丢失清理拖拽及按键，退出时释放事件监听。

## 参考与布局依据

`assets-source/campus-3d/district/reference/` 保留：

- `district-user.png`：用户选定的无标注地图区域。
- `district-names-user.png`：用户提供的楼名标注图。
- `ground-layout-trace.jpg`：青色地面占地、黄色道路轴线、蓝色湖岸的参考对照图。楼顶高度造成的上移不作为占地。
- `sources.json`：授权、制作方法与估算范围。

继承思源楼局部区块的地面轴向与 1.55 逻辑单位／参考地面像素比例，将既有三栋楼整体偏移 `(192,96)` 逻辑单位，拓展到 `3264×3328`。32 逻辑单位等于 1 场景单位。截图对照投影采用 30°斜视地面基；总览采用固定相机，人物模式可环绕，建筑和碰撞坐标不随镜头改变。

所有建筑部件、道路、湖面、岸线、树位、球场和碰撞均读取 `assets-source/campus-3d/district/layout.json`。第九教学楼使用多块占地保留院落；水域按湖岸多边形分格阻挡，避免用一个大矩形封住岸边通路。校门只阻挡两侧门柱，门洞可通行。

除既有银杏大道、知行大道、明湖路外，配置中的“南门主路”“教学区横路”等是描述性称呼，不作为官方路名。未逐一还原截图中的小水池、每株树和雕塑细节。

## 源文件与运行

```powershell
# Python 环境需 Pillow；先从已保留参考生成布局
python scripts/create_campus_district.py

# 生成可编辑 Blender 源文件与运行时 GLB
& 'E:/Blender/blender.exe' --background --factory-startup --python scripts/build_siyuan.py -- --district

npm.cmd run dev
```

- Blender：`assets-source/campus-3d/district/district.blend`。
- 浏览器模型：`public/assets/models/bjtu-district/district.glb`。
- 制作报告：`public/assets/models/bjtu-district/asset-report.json`。
- 新环境建模脚本：`scripts/build_district_environment.py`，由共享构建脚本提供材质、基础物件函数及布局上下文，不单独执行。

源文件保留可编辑楼体、窗格、树和道路；运行时按建筑／区域和材质合批。模型优化采用 glTF Transform 的 `dedup` / `prune`，并用 Khronos glTF Validator 检查。重新导出后必须重新校验，不能沿用旧报告。浏览器不依赖外部官网请求；参考图不当作地面或盒体贴图。

显示层按建筑独立处理遮挡淡化，避免人物经过一栋楼后时整个校园一起变透明。场景中的悬浮名称说明牌已按用户要求删除，人物模式与区域总览都不再生成这些牌子。纹理、几何、材质、静态阴影与事件监听在退出时释放。

## 玩法与存档

首版出生于南门外侧。南门主路沿线布置四个宝箱，可继续探索思源楼、明湖和图书馆附近的另外四个宝箱。沿用 6 格背包、每箱价值 25、搜索 2 秒、门槛 100、撤离 5 秒和 10 分钟时限。所有宝箱都有可达性检查。

独立存档前缀 `bjtu-campus-3d:district:v1:`，锁 `bjtu-campus-3d:district:save`，音量键为该前缀加 `audio`。不把奖励写入原 Phaser、南门样板或思源楼样板存档；各版本通过独立网址访问。

## 验收记录

最新模型校验与性能以 `asset-report.json` 和忽略目录中的 `artifacts/campus-3d/district-browser-report.json` 为准。测试覆盖：建筑身份和前后位置、两条楼间道路、水域阻挡、校门净空、第九教学楼院落、八箱可达性，以及实际移动搜索四箱并返回撤离。导出模型另外核对全部建筑的实际包围盒、校门高度与坐标、湖面坐标及外部资源依赖。

- 模型 123 个网格、109,308 三角形，优化后 5,093,352 字节，无外部贴图；Khronos 校验 0 错误、0 警告。路面在交叉口合并为无重叠平面，避免共面黑斑。
- 环绕相机更新后全量单元／集成测试 63 文件、433 项通过（`npm.cmd run test:unit -- --maxWorkers=1`）。lint、typecheck 和 build 通过。新增测试覆盖相机相对移动、四方向精灵朝向、俯角／缩放上下限、30／60 FPS 跟随一致性、碰撞收近及恢复、刷新鼠标地面指向、暂停清理拖拽和 Esc 原生行为。
- Edge 无头、1600×1000：实际按键搜索四箱得到 100，沿南门主路走到思源楼，再沿银杏大道到明湖和图书馆，原路返回并撤离保存、再开局；未使用传送、加分或修改背包。与思源楼样板在同一浏览器中同时开局，存档和锁互不冲突。
- 最新正式构建在 `/demo/` 子目录完整重复上述流程通过，未请求外部官网资源或 Phaser 包，页面无运行错误。
- 首版固定镜头的历史采样约 59 FPS、平均 17.0 ms、P95 16.9 ms。更新后的环绕相机在实际拖动 90°后采样约 58 FPS、平均 17.2 ms、P95 17.3 ms，57 次绘制；滚轮缩放后约 59 FPS。人物模式因相机方向和碰撞收近而改变绘制次数，不能由局部画面推断所有设备的总览性能。

- `npm.cmd run check` 仍停在原有 `src/main.ts`、`docs/delivery/d-changelog.md` 的格式检查，未改动这两处无关文件。构建保留原页面已有 `zpix.ttf` 提示；未重新验证正式游戏的登录／联机浏览器全流程。
