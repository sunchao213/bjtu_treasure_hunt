# 南门三维试验区验收记录

后续 Blender 南门样板的资源调查、模型交付和新验收记录见
[南门样板说明](campus-3d-south-gate.md)；下文保留最初低模版本的验收结果。

## 自动化

运行 `npm.cmd run check`：格式、ESLint、严格类型检查、41 个测试文件／312 项测试及双页面构建通过。

新增九项三维会话测试覆盖：

- 坐标转换、四方向横向动画索引与非循环动作结束帧。
- 建筑／树干占地、门洞通行、斜向移动速度与低帧率碰撞。
- 通过真实移动输入走到八个固定搜索点，不在测试中直接修改人物位置。
- 三局连续“搜索四件→撤离→结算→再开局”，以及重复结算不重复奖励。
- 松键、移动、受伤和暂停取消搜索，暂停不消耗对局时间。
- 满包后搜索点保留，丢弃／拾回保留同一实例及来源，释放空间后可搜索剩余点。
- 价值不足禁止撤离；离区、受伤和丢弃导致价值下降取消撤离。
- 库存插入失败保留宝箱；存储失败保留结算并可重试。
- 超时、死亡、刷新中断、试验存档／旧数据查询命名空间与独立锁。

现有音效测试增加独立音量设置键回归，默认设置键保持原行为。

## 性能观测与限制

- 系统：Windows，本机 CPU 为 Intel Core i5-1135G7；GPU 型号未取得，未把结果标为特定显卡基准。
- 浏览器：Codex 内置 Chromium；1920×1080 验收视口，设备像素比上限 1.5。
- 一次稳定窗口约 60 FPS，平均帧时间 16.8 ms，P95 17.0 ms。
- 后续另一采样窗口约 51—53 FPS，平均 19.0—19.7 ms，P95 33.7 ms。自动化工具切换和后台状态会影响采样，因此不声明稳定锁定 60 FPS。
- 静态场景采样：79 次绘制、79 个几何体、7 张纹理；没有掉落时的计数，不是显存字节数。
- 控制台未观察到场景加载错误。静态投影缓存减少重复阴影绘制，像素比受限，没有后期处理。
- 内置指标可在暂停面板展开查看。没有跨显卡、手机性能、长时间显存分析或网络限速测试。

WebGL 上下文丢失／恢复和卸载释放已有代码处理，但本次未在浏览器中主动触发显卡上下文丢失；不将该路径记为人工验证通过。连续三局逻辑重置由自动化验证，浏览器完成成功后再次开局与主动放弃。敌人、战斗、夜间照明、手机双摇杆、室内与楼层不属于首版交付。
