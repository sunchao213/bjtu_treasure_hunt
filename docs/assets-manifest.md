## 仓库网格规格

仓库格子是「5 列 × 20 行」滚动区（100 格）。几何以美术定稿为准：

- **定稿真值**：`text-gen/cells/仓库界面-藏品选中-790x872.png`（790×872）。逐像素实测：格子区从 (26,232) 起，槽 133×158，横纵间距都是 17；15 格在整片网格里逐像素相同（可平铺），右缘 759，滚动条凹槽 763..771。
- **现行实现**：`src/warehouse-panel.css`（`.wh-scroll` / `.wh-grid` / `.wh-slot`），面板逻辑基准 790×890（cqw 只看宽度，1cqw = 7.9px 不变），格子区仍按定稿 232..740。

| 项目       | 定稿实测（面板内）                                                                                                                          | 现行 CSS                           |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------- |
| 列左边界   | 26 / 176 / 326 / 476 / 626                                                                                                                  | 26 / 176 / 326 / 476 / 626         |
| 列宽       | 133 × 5                                                                                                                                     | 133（`16.8354cqw`）                |
| 列缝       | 17                                                                                                                                          | 17（`2.1519cqw`）                  |
| 行上边界   | 232 / 407 / 582                                                                                                                             | 232 / 407 / 582                    |
| 行高       | 158 × 3                                                                                                                                     | 158（`20cqw`）                     |
| 行缝       | 17                                                                                                                                          | 17（`2.1519cqw`）                  |
| 格子区     | 26..759 × 232..740                                                                                                                          | 26..759 × 232..740（视口 733×508） |
| 右缘       | 759（滚动条凹槽 763..771 在右侧）                                                                                                           | 759（`.wh-bar` 763..770）          |
| 面板其余件 | 分类栏 (22,144) 499×66；容量凹槽 275..426、＋按钮 427..467、交子图标 607..632；提示两行 ..803；一键整理 (282,819) 240×62、底框横线 882..884 | 百分比一一对应（分母 890）         |

**面板在舞台上的落点**：`.bp-wh` 尺寸 790×890，`top: 24px`（2026-11-26 按用户要求与右上徽章一起从 44 上移 20px）。底边 914，舞台 941 内余 27px 砖墙（顶部 24 / 底部 27，比原 44/7 均衡）。面板比定稿高 18px 是给「一键整理」完整按钮腾的位置（底框下移），不是顶边抬了。顶边 24 比左背包（底图烘焙，60）高 36px——参考图二里仓库标题框本来就比背包高，属预期。

`3×158 + 2×17 = 508` 正好等于滚动视口高度，第三行完整露出；`5×133 + 4×17 = 733` 正好等于视口宽度。

**为什么不再「擦格子 + DOM 重绘」**：定稿的 15 格本身就是等距标准格（v4 那版第三排被压扁 28px、第 5 列窄 11px，才需要擦掉重铺）。现在 DOM 的 `.wh-slot` 贴图就是从定稿裁下来的同一格（`slot.png`，133×158），首屏 3 行与面板图逐像素同位，等于叠了一层同样的图；滚到第 4 行以后继续用这张贴图铺。

改格子尺寸时必须同步四处：`.wh-grid` 的 `grid-template-columns`、`.wh-slot` 的 `width/height`、`slot-*.png` 素材、`.wh-slot > img` 与 `.wh-slot-name` 的百分比。改完跑 `node scripts/probe-grid.mjs`（打印每格与滚动条的面板内坐标，并滚到底截图核对空槽底图）、`node scripts/probe-tab3.mjs`（三态分类栏背景图）。
