# 第一轮迭代交付基线

更新日期：2026-10-30。本文按最新 A–E 分工汇总第一轮应交付的系统基线。

## 已落地

- A：地图、移动碰撞、搜索、撤离状态机、异常中断、统一事件和模块接线。
- B：装备槽、容量规则、恢复物消费、掉落实例来源、正式存档 v3、旧存档迁移和幂等结算。
- C：真实武器攻击、敌人状态机、抱抱/变异流程、敌人掉落和 `DamageTaken`/`EnemyDefeated` 事件。
- D：大厅、行前准备、HUD、背包、图鉴、剧情前置、章节解锁、移动端布局。
- E：统一检查脚本、单元/集成测试、CI、发布核对清单。
- 联机边界：版本化 WebSocket 消息协议、运行时校验、连接状态、断线重连和服务端权威约束。
- 联机服务：8 人临时房间、方向输入、服务器推进位置、房间快照广播及同图远端玩家显示。

## 第一轮验收清单

| 编号  | 场景                  | 结果标准                                                                        |
| ----- | --------------------- | ------------------------------------------------------------------------------- |
| R1-01 | 选择训练棍/电击器开局 | 武器进入主武器槽，不占背包格；未知武器拒绝开局                                  |
| R1-02 | 攻击敌人并击败        | 生命扣减只经过 `RaidController.applyDamage`；击败后按实例 ID 生成掉落           |
| R1-03 | 拾取、丢弃、重拾掉落  | 来源和实例 ID 保持不变，不可刷撤离价值                                          |
| R1-04 | 恢复物使用            | 只有恢复成功才消耗物品；满血或非恢复物拒绝消费                                  |
| R1-05 | 成功/失败/刷新结算    | 存档写入幂等；带入物失败损失，未带入仓库物保留；旧活动局迁移为中断失败          |
| R1-06 | 任务前置与章节解锁    | 手记和羽毛均为本局所得并成功撤离后解锁章节                                      |
| R1-07 | 联机房间              | 两浏览器加入同一房间可见彼此移动；不同房间隔离；断线自动重连；非法消息被拒绝    |
| R1-08 | 发布基础检查          | lint/typecheck 通过；测试和 build 在具备 esbuild 子进程权限的环境执行并记录结果 |

## 未包含在第一轮完成声明中

- 联机账号系统、服务器权威存档、跨客户端战斗/掉落结算和公开 WebSocket 地址。
- 真实 iOS/Android 设备、教学机和公开网址验收。
- 开源许可证和用户素材再分发授权确认。
