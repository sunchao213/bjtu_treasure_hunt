## 官网核对与纠正

此次重新读取 <https://map.bjtu.edu.cn/> 主页面、zoom2 列 24—29／行 23—26 的 24 张高清地图瓦片，并检查全景：

- `qj/bjdzx90/index.html`：官网标记名“饮水思源碑”，坐标 `(13853,12472)`，配置节点 `node40`。现场画面可看到圆形花坛／碑、其后思源楼、两侧树木和向南的道路。
- `qj/bjdzx93/index.html`：东校区南门，节点 `node82`，核对门内树木及轴向连接。
- `qj/bjdzx101/index.html`：思源楼入口；`qj/bjdzx97/index.html`：天佑会堂入口。

全景先读取完整低清立方体面（`l_0/c_0/tile_0.jpg`）；`l_3/c_0/tile_0.jpg` 是高清面左上分块，不能当成整个方向的照片。保留六个完整方向拼图用于审计，没有把蓝色施工围挡等临时设施放进永久模型。

核实后的空间顺序为：**思源楼前道路与旗杆 → 完整大草坪 → 南端饮水思源碑 → 横向道路和窄绿化岛 → 树阵小广场 → 停车带和南门**。草坪西侧为档案馆、天佑会堂一带，东侧为教学区；道路走两侧，不能从草坪中间贯穿。

旧版“南门主路”穿过草坪、小草坪放在档案馆侧、南门广场仅为窄绿化条，这三处属于旧版布局错误，本次已替换。第七教学楼、第九教学楼及附近附属体的横向间距同时校准，给官网图中的真实开放空间留出位置。第九教学楼保留上一轮精修形体及侧面通道，位移后的碰撞同步更新。

## 已建内容与玩法

- 连续大草坪，边缘行道树与内部六株疏落针叶树；移除草坪中的横穿道路和密集随机树。
- 思源楼前旗杆、浅色基座、普通红旗；不制作不可辨认的纹章细节。
- 南端圆形石质景观台、红色花坛、细柱与金属冠部，表达饮水思源碑现场轮廓。
- 草坪南侧横路、窄绿化岛和简化雕塑；南门小广场的红色边缘、浅色铺地、错列树阵、座椅及停车位线。
- 小地图使用相同草坪／广场多边形。角色可在草坪与广场通行，树干、碑和旗杆基座设碰撞，主路改走草坪两侧。宝箱随道路调整位置，不挪动景观来迁就玩法。

`layout.json` 中 `forecourt` 是草坪、广场、旗杆、碑、停车带等共享配置。`scripts/build_forecourt.py` 被完整构建共用；`scripts/refine_forecourt.py` 只重建地面、树与景观，保留现有精修建筑，并以源文件标记防止位移重复累加。

```powershell
python scripts/create_campus_district.py
python scripts/trace_forecourt_reference.py
& 'E:/Blender/blender.exe' --background --factory-startup --python scripts/refine_forecourt.py
```

更新后的可编辑源文件为 `assets-source/campus-3d/district/district.blend`，游戏模型为 `public/assets/models/bjtu-district/district.glb`。导出后重新优化并执行 Khronos glTF 校验，结果以该目录 `asset-report.json` 为准。
