## 第一次联调应实际操作

1. 不带物出发，未达100尝试撤离：拒绝。
2. 四个稀有物值100，原地读条5秒：成功，刷新准备页仓库仍在。
3. 从仓库带入一件，开局价值0；丢下再捡仍然不计分。
4. 背包价值100时开始读条，丢弃25价值物：取消；捡回后需要重新读满5秒。
5. 开发环境模拟受伤：取消搜索与撤离。模拟死亡：失败，带入物损失，未带入仓库物保留。
6. 搜满6格后再搜索：不吞物；先丢弃再重试。
7. 开局刷新：下次加载显示中断失败。另开同源标签页：禁止并行写档。

不使用开发快捷加分作为验收证据；95/100临界、超时竞态和存档失败通过自动测试覆盖。
