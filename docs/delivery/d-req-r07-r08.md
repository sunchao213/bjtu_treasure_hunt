# D 模块需求条目：R07 主线与章节解锁 / R08 界面与操作

> 版本：V1.0 初稿（2026-10-25）　负责人：丁璟怡（D）　协作：B（R07 存档落库）、A（R08 大厅与局内框架）
> 编号规则：`R07-xx` / `R08-xx`，每条需求对应 `d-cases-r07-r08.md` 中的用例编号。

## 一、R07 主线与章节解锁

| 编号   | 需求                                   | 验收标准                                                                                   |
| ------ | -------------------------------------- | ------------------------------------------------------------------------------------------ |
| R07-01 | 主线两条线索必须按顺序推进             | 未持本局「残缺手记」时，调查明湖石碑被拦截并给出「先取得残缺手记」提示；持手记后可正常调查 |
| R07-02 | 证据只认本局获取的物品                 | 从仓库带入的手记/羽毛不推进任务、不计入证据；任务卡进度保持 `0 / 2`                        |
| R07-03 | 两件证据同时带出且撤离成功才解锁第一章 | 结算成功且背包同时含两件本局证据 → 图鉴档案出现「回看第一章剧情」；缺任意一件 → 保持未解锁 |
| R07-04 | 主线是可选目标，不阻断普通撤离         | 未接下主线也能按价值达标正常撤离并结算成功，只是不解锁章节                                 |
| R07-05 | 失败路径一律不解锁                     | 死亡、超时、主动放弃、刷新中断（按失败恢复）后，章节仍为未解锁                             |
| R07-06 | 重复获得同一件证据不重复计数           | 丢弃后重拾、同局多次打开同一搜索点，进度仍为最多 2 件，价值按实例去重                      |
| R07-07 | 任务状态必须可读                       | 任务卡显示 `n / 2`、两步各自状态；状态文案按「未开始 / 有手记 / 线索齐备」三档切换         |
| R07-08 | 章节内容需可回看                       | 解锁后档案页可打开第一章剧情（三段线索 + 章节小结），未解锁时显示解锁条件                  |
| R07-09 | 文案不得承诺范围外功能                 | 主线与结算文案中不出现「互助组 / 组队 / 联机 / 排行榜」等未实现功能                        |

## 二、R08 界面与操作

| 编号   | 需求                     | 验收标准                                                                                                             |
| ------ | ------------------------ | -------------------------------------------------------------------------------------------------------------------- |
| R08-01 | 提供大厅作为唯一入口     | 进入游戏后可在大厅完成：看任务简报、选装备、勾选风险、开始探索；导航只出现 V1.0 范围内页面（出发准备 / 仓库 / 设置） |
| R08-02 | 行前准备可切换三档带入   | 轻装/标准/重装切换后，带入清单与仓库占用同步变化；未勾选风险提示时「开始探索」不可用                                 |
| R08-03 | HUD 常驻显示四项状态     | 生命、剩余时间、本局价值（含门槛）、手电电量在同一屏内可见，数值随对局变化                                           |
| R08-04 | 背包 6 格，可丢弃与使用  | 超过 6 件时拒绝拾取并提示；丢弃后本局价值下降；使用消耗品后有可见反馈                                                |
| R08-05 | 仓库展示永久物品         | 仓库页显示永久物品数量与图鉴入口，并可导出/导入/重置存档（逐件明细列为 V1.1 增强）                                   |
| R08-06 | 图鉴可查看与导出         | 打开图鉴能看到已点亮/未点亮的全部条目及说明，可导出为图片                                                            |
| R08-07 | 结算界面覆盖四种状态     | 成功、失败、结算中、保存失败（可重试）四种状态各有明确文案与可操作项                                                 |
| R08-08 | 桌面键鼠可独立完成一局   | 只用键盘鼠标即可完成：移动、开手电、搜索、安抚、撤离、查看背包与图鉴                                                 |
| R08-09 | 移动端横屏可独立完成一局 | 竖屏提示旋转；旋转后双摇杆 + 交互键可完成移动、搜索、撤离；全屏被拒时有降级提示                                      |
| R08-10 | 界面不出现未实现功能     | 大厅与局内不出现好友、组队、商店、排行榜等范围外入口；不出现「在线 / 服务器稳定」等上线状态描述                      |
| R08-11 | 异常有可见反馈           | 存档失败、刷新中断、背包已满、撤离被拒绝（差额/区域/暂停/中断）都在画面内或状态行给出原因                            |

## 三、边界与非目标

- 不做：多人联机、好友与组队、商店与经济、排行榜、云端账号、新校区、新任务链、难度模式。
- 不做（2026-10-25 决策）：剧情「已读」进度——不记录已读标记、不做续播与跳过；章节只要求可回看。
- 不改变核心规则：界面与美术调整不参与价值、撤离、解锁的判定，只消费已有快照。
- 数据边界：解锁落库由 B 的存档模块执行，D 只提供界面与状态文案，不直接写存档。
