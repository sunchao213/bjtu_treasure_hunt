# D 模块概要与详细设计：R07 主线与章节解锁 / R08 界面与操作

> 版本：V1.0 初稿（2026-10-25）　负责人：丁璟怡（D）
> 代码位置：`src/modules/ui/`、`src/modules/quests/`、`src/main.ts`、`src/style.css`、`src/mobile-layout.css`

## 1. 概要设计

### 1.1 模块职责

- **R07 主线**：线索状态判定（是否持有本局证据）→ 地点前置校验 → 章节解锁条件 → 任务卡与图鉴档案呈现。判定逻辑在 `quests/quest-service.ts`，内容在 `quests/chapter-content.ts`，界面在 `ui/quest-view.ts`，落库由 B 的 `save/persistent-save.ts` 执行。
- **R08 界面**：大厅（准备页）、局内 HUD、背包、仓库、图鉴、结算，以及桌面键鼠与移动横屏两套输入。界面只消费 `RaidView` / 存档快照，任何判定都回到业务层。

### 1.2 分层与数据流

```
存档(save) ──快照──► main.ts（编排/渲染）──► ui 模块（纯渲染）
      ▲                    │
      │                    └──► scenes/world-scene（输入、交互、画面内提示）
      └──结算(finalizeRaid)◄── modules/raid/raid-controller（权威状态）
```

- 渲染函数一律「入参即状态」，不读全局、不写存档（`quest-view.ts` 注释明确此约定）。
- 局内提示分两层：状态行 `#notice`（兜底）与画面内 `#map-toast`（撤离等即时反馈）。

## 2. 详细设计

### 2.1 R07 状态机

```
未取得手记 ──搜索「图书馆外·旧书架」──► 持有手记 ──调查「明湖石碑」──► 持有手记+羽毛
     │                                     │（代入物品无效，仍停在未取得）        │
     │                                     └──死亡/超时/放弃──► 失败（不解锁）    │
     └──────────────────────────────普通撤离（价值≥门槛）──► 成功，但章节仍锁定    │
                                                                            ▼
                                                     结算成功 ──► 解锁第一章 ──► 档案可回看
```

- 前置校验：`prerequisiteHint(chestItemId, items, raidId)`，仅对「异常羽毛」拦截，返回文案由界面直接展示。
- 证据判定：`carriedEvidence(items, raidId)` 过滤 `origin.kind === 'raid-loot' && origin.obtainedInRaidId === raidId`。
- 解锁判定：`chapterUnlockGranted(result)` = `outcome === 'success'` 且 `questComplete` 且两件证据齐全。
- 幂等：落库前检查 `unlockedChapterIds` 是否已含章节号；重复结算由 `settledRaidIds` 拦截。

### 2.2 R07 界面状态

| 界面位置   | 数据来源                    | 状态表现                                                         |
| ---------- | --------------------------- | ---------------------------------------------------------------- |
| 任务卡标题 | `questProgress().collected` | `0 / 2`、`1 / 2`、`2 / 2`                                        |
| 任务步骤   | `stepState()`               | 已完成（实心）/可进行/未开始（`title` 提示需要手记）             |
| 任务状态行 | `progress.statusText`       | 未开局 / 线索一 / 线索二 / 线索齐备                              |
| 图鉴档案   | `unlockedChapterIds`        | 未解锁：显示 `unlockHint`；已解锁：显示小结 + 「回看第一章剧情」 |
| 结算面板   | `chapterUnlockGranted()`    | 显示本章解锁摘要；未解锁时说明缺哪一件                           |

### 2.3 R08 页面结构

- **大厅**：左导航（行动中心：出发准备 / 仓库；系统：设置）+ 中区内容 + 右侧「开始探索」。范围外的商店、好友/邀请入口隐藏（代码保留，排期后恢复）。
- **行前准备**：任务简报、三档装备带入、带入清单校验、风险勾选、开始探索。
- **局内**：顶部生命/剩余时间；地图画布 + 交互条 + 画面内提示；右侧价值/装备/任务/背包/撤离；底部状态行。
- **仓库**：永久物品数量、图鉴入口、存档导出/导入/重置。
- **图鉴**：条目列表（点亮/未点亮）+ 说明 + 导出 PNG + 章节档案。
- **结算**：成功/失败/结算中/保存失败重试，返回准备。

### 2.4 R08 输入设计

| 动作                       | 桌面                         | 移动横屏   |
| -------------------------- | ---------------------------- | ---------- |
| 移动                       | W A S D / 方向键             | 左摇杆     |
| 瞄准/朝向                  | 鼠标移动                     | 右摇杆     |
| 调查与互动                 | E（搜索需长按 2 秒）         | 交互键     |
| 安抚抱抱怪                 | Q                            | 交互键长按 |
| 攻击                       | 空格                         | 攻击键     |
| 手电开关 / 换电池 / 照明棒 | L / R / G                    | 工具条按钮 |
| 面板                       | 背包、图鉴、规则、校园图按钮 | 移动工具条 |

- 竖屏进入时给出旋转提示；全屏请求被拒时降级为页面内横屏排版。

### 2.5 异常与降级

| 场景         | 表现                                         | 归属                 |
| ------------ | -------------------------------------------- | -------------------- |
| 存档写入失败 | 结算面板提示 + 重试按钮，保留本局结果        | D（界面）/ B（存档） |
| 刷新中断对局 | 恢复为「按失败处理」并把物品扣留，状态行说明 | B / D                |
| 背包已满     | 拦截拾取与搜索，给出丢弃提示                 | D                    |
| 撤离被拒绝   | 画面内提示差额/区域/暂停/中断原因            | D                    |
| 章节未解锁   | 结算说明缺少的证据                           | D                    |

### 2.6 与其他人接口

- **B**：`unlockedChapterIds`、`codexIds`、`warehouse` 由存档模块提供；D 不写存档，只读快照。
- **A**：大厅与局内框架的挂载点（`#lobby`、`play-layout`）、`RaidView` 字段（价值/门槛/区域/读条/暂停）由控制器提供。
- **C**：局内交互条与场景提示由 `world-scene` 输出，撤离拒绝的统一文案在 `ui/extraction-feedback.ts`，两边口径需保持一致。
