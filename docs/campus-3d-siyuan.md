# 思源楼参考建模与局部布局

开发入口：<http://localhost:5173/campus-3d.html?area=siyuan>。南门样板仍在不带参数的 `campus-3d.html`，页面右上角提供互访链接。原 Phaser 页面没有切换或布局改动。

## 已完成的范围

- 三栋独立建筑：左侧思源西楼、中间思源楼、右侧思源东楼；删除原先误做的两处连接体，楼间由道路隔开，可从银杏大道通往楼后道路。
- 按用户两张参考图片分别调整东、西楼的立面。西楼采用右侧单塔、蓝色玻璃楼梯间、平屋顶及屋顶设备；东楼采用左侧单塔、玻璃楼梯间、偏置入口和屋顶设备，二者不再套用中央思源楼的双塔造型。
- 信息中心在西楼后方，科学会堂在东楼后方，已加入小地图的待建方位标记；两处尚未制作建筑模型，也不会被并入思源西楼／东楼。
- 银杏大道、知行大道、明湖路、正门入口及两条楼间通路。道路与小地图读取同一份数据，“西侧楼间路／东侧楼间路”为描述性称呼，未宣称为官网路名。
- 人物模式已升级为透视环绕镜头：鼠标拖动旋转、滚轮缩放、R 重置，WASD／方向键按镜头方向移动。鼠标指向、建筑碰撞、搜索、背包与撤离继续保留，人物移动速度不变。固定总览位于连续校园区块页面。
- 保留八个宝箱及原试验玩法。绿色区域是**玩法集合点**，不是官网校门或真实设施。
- 南门和思源楼各自保存、各自加锁，可同时打开，不把两处在真实地图上相隔的区域强行拼在一起。

这是一版**参照官网斜视图、用户截图及建筑身份纠正重建的缩略样板**。三个建筑的身份和分离关系以用户说明为准；楼间路宽、楼高、遮挡背侧、窗口分格与局部细节仍为估算，不能宣称已经与实际校园精确一致。当前只制作思源楼局部区块，尚未建立完整校园；信息中心、科学会堂、湖岸和精确树位仍待补充。道路在该截图覆盖范围外的弯折也尚未制作。

官网已检查的展示路径提供 JPG 地图与 Pano2VR 全景，并未提供对应楼体网格。本次没有将全景照片贴在盒子上冒充模型，运行时也不请求官网。

平面采用从官网地面线条推断的 30°斜视基，`u` 沿楼前大道方向、`v` 沿明湖路方向。参考截图地面锚点 `(340,850)` 对应官网 zoom1 图像地面点 `(12456,11940)`，映射到试验逻辑坐标 `(650,850)`。一个参考地面像素映射为 1.55 逻辑单位，32 逻辑单位等于 1 场景单位。这个比例用于游戏缩略表现，不是实测米制比例。

`src/campus-3d/siyuan-coordinates.ts` 提供官网 zoom1 **图像地面点**与试验坐标的双向换算。后续建筑先找地面锚点，再沿同一基准追加，不能用屋顶标签坐标摆放。高度引起的屏幕上移不会进入碰撞位置。小地图不标注未经核实的地理北向。

## 源文件与再生成

- `assets-source/campus-3d/siyuan/layout.json`：楼体占地、楼高、道路、树位、宝箱、出生和集合点。
- `assets-source/campus-3d/siyuan/siyuan.blend`：Blender 5.2.3 LTS 源文件，保留独立物件、可编辑材质及 55°预览相机。
- `scripts/create_siyuan_layout.py`：从保留的参考图生成占地与对照图，需要 Pillow；首次取图过程不在运行时执行。
- `scripts/build_siyuan.py`：Blender 建模与导出脚本。建模采用 Z 向上，导出 glTF 后为 Y 向上、逻辑 y 对应 Z。
- `public/assets/models/bjtu-siyuan/siyuan.glb`：运行时模型；不依赖外部贴图。
- `public/assets/models/bjtu-siyuan/asset-report.json`：面数、体积、材质与验证记录。

```powershell
& 'E:/Blender/blender.exe' --background --factory-startup --python scripts/build_siyuan.py
npm.cmd run dev
```

修改布局后重新导出模型；三栋楼的三块占地同时供移动碰撞与模型生成使用。模型保留各楼分区并按材质合批；当建筑遮住人物时暂时淡化，恢复不透明后重新启用深度写入，避免屋顶盖住尖顶和窗口。树只在树干附近阻挡。两条楼间路不加入建筑碰撞；悬浮名称说明牌已按用户要求删除。

现版优化采用 glTF Transform 的 `dedup` / `prune`，使用 Khronos glTF Validator 检验。重跑 Blender 会得到未优化导出，需重新执行同样优化和验证，不能把旧报告视为新模型验证结果。导出本身仍可由 GLTFLoader 直接读取。

- 同一浏览器中保留思源楼页并打开南门页，双方均可开局，没有存档锁冲突。3D 页未加载 Phaser 或外站资源。
- 子目录部署的首版记录：正式构建放在 `/demo/`，实际按键搜索四箱、碰撞、撤离保存和再开局成功。此次拆分楼群后重新构建通过，楼间道路与完整流程在开发页面实测；本轮没有重跑原游戏的登录／联机全流程浏览器测试。
