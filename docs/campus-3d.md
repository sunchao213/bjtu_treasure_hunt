# 南门漫游 · 独立三维校园试验区

新增 [南部校园连续区块](campus-3d-district.md)：`campus-3d.html?area=district`，按用户选定范围连接主要建筑、明湖、道路、庭园和球场，支持区域总览与人物跟随。

人物跟随已升级为第三人称环绕：鼠标左／右键拖动、滚轮缩放、R 重置，移动方向与精灵朝向随镜头转换；连续区块继续保留固定总览。

已接入基于交大虚拟校园南门参考重建的 Blender / GLB 样板，替换初版占位门梁与教学楼。
资源格式调查、源文件、再生成和最新验收见 [南门样板说明](campus-3d-south-gate.md)。

新增 [思源楼局部区块](campus-3d-siyuan.md)：`campus-3d.html?area=siyuan`。左侧思源西楼、中间思源楼、右侧思源东楼互相独立，楼间道路可通行；后方信息中心、科学会堂以待建标记表示。使用独立存档，南门样板保留。路宽、楼高和遮挡处轮廓仍为估算。

## 运行

在项目根目录使用项目约定的 Node 24 / npm 11：

```powershell
npm.cmd ci
npm.cmd run dev
```

- 原 Phaser 游戏：<http://localhost:5173/>
- 三维试验区：<http://localhost:5173/campus-3d.html>

三维页有独立 HTML、TypeScript 入口、CSS、画布、输入和循环，不导入原 `main.ts`、Phaser 场景或完整大厅。两个页面可以同时打开；同一浏览器内同时打开两个三维页时，后打开的页面因独立存档锁而停止启动。

`npm.cmd run build` 同时生成 `dist/index.html` 和 `dist/campus-3d.html`。`npm.cmd run preview` 可验证正式构建。部署时上传完整 `dist`，三维入口为站点路径下的 `campus-3d.html`。图片和音效使用 Vite 的 `BASE_URL`，支持子目录部署。

## 如何玩完整一局

1. 等待角色和宝箱加载完毕，阅读失败规则并勾选确认，点击“开始这次漫游”。
2. 用 WASD 或方向键移动；沿金色圆环寻找宝箱，小地图数字对应八个固定宝箱。
3. 走到宝箱附近停下，长按 E 两秒。移动、松键、受伤或暂停会取消搜索。
4. 每个宝箱提供 25 价值。搜索四个后达到 100；背包可装六件。
5. B 打开背包并暂停，点击“丢弃”会把物品留在脚边，返回探索后可按 E 拾回。满包不会消耗未打开的宝箱。
6. 回到南门浅绿色区域，按 E 启动五秒撤离。留在区域内等待结算；离开、受伤、暂停或价值跌到 100 以下会取消。
7. 成功物资进入试验收藏，重复收藏按原库存规则兑换交子。点击“再逛一次校园”返回开始面板。

每局十分钟。失败、超时或局中刷新会失去本局物资。没有敌人的首版仍复用受伤／死亡显示与失败规则，供后续战斗接入。Esc 打开暂停；失去焦点或切后台自动暂停，返回后需要主动继续。白天搜索使用距离与占地遮挡，不需要手电。

## 代码与数据边界

- `src/campus-3d/main.ts`：独立页面、资源准备、存档锁、HUD、背包、暂停和结果；加载完成后才可开局。
- `session.ts`：引擎无关试验会话，组合现有 `movePlayer`、`SearchInteraction`、`ReferenceInventory`、`RaidController` 和 `EventBus`。
- `map.ts`：1024×768 逻辑地图；物件、树干与建筑碰撞、出生点、固定宝箱和撤离区域的单一配置。
- `view.ts`：Three.js 显示适配器，初始化／渲染／尺寸更新／资源释放；不负责入包、碰撞或成功判定。
- `input.ts`：键鼠适配器，输出 `TrialInput`。后续触屏适配器应输出相同结构。
- `animation.ts`：方向、帧率和横向帧索引规则。
- `storage.ts`：所有存储读写统一加试验前缀，包括旧格式查询。

地图逻辑 x 映射三维 X，逻辑 y 映射三维 Z，三维 Y 表示高度；32 逻辑单位等于 1 世界单位。玩家速度 145、半径 8、搜索距离 60 均保留原逻辑单位。模型尺寸和碰撞占地分别声明；树干阻挡，树冠参与画面遮挡。首版平地移动不需要三维物理引擎。

原地图轮换和全局 `activeMap` 不参与三维会话。三维页不导入依赖原地图的夜巡模块，避免把原坐标或手电条件带入试验区。共享音效设置键与存档锁增加可选参数，旧调用保持默认值。

### 存档隔离

- 前缀：`bjtu-campus-3d:v1:`，实际持久化键为该前缀加现有 `FORMAL_SAVE_KEY`。
- 锁：`bjtu-campus-3d:save`，与原游戏锁独立。
- 音量设置：`bjtu-campus-3d:v1:audio`。
- 不导入正式仓库，也不提供试验奖励转移或章节解锁。
- 复用原存档校验、原子写入、刷新中断恢复、防重复结算和保存失败重试。损坏数据不会自动清空覆盖。

### 画面与资源生命周期

人物模式使用透视环绕相机，以角色胸口附近为焦点平滑跟随，支持拖动、缩放和碰撞收近；区域总览保留固定正交相机。像素角色面片朝向相机，以脚底为原点，通过横向 UV 帧索引和相机相对方向播放动画；透明裁切和深度测试处理与模型的遮挡。人物使用接触阴影，静态建筑与树木共享一盏方向光的 1024 阴影贴图，静态阴影只在初次绘制和上下文恢复时更新。

设备像素比上限 1.5；不使用复杂后期。暂停面板的“显示设置与运行信息”包含平均帧时间、P95、绘制次数和几何／纹理数量。这些是当前浏览器的采样数据，不代表所有设备都达到 60 FPS。

页面卸载和 Vite 热更新释放输入监听、动画循环、声音、地图几何、材质、纹理、阴影资源、ResizeObserver 和锁。连续开局复用场景资源，仅重置对局状态与掉落。WebGL 上下文丢失会暂停并取消交互，恢复后重新建立显示资源并等待玩家主动继续。

## 测试与后续阶段

`tests/unit/campus-3d.test.ts` 用实际移动输入而非传送来验证八个宝箱的可达性、三局搜索与撤离、丢弃拾回、满包保留、搜索和撤离取消、入包失败、超时、死亡、刷新恢复、重复结算、写入重试，以及存档和锁隔离。共享声音测试补充独立设置键回归。统一检查命令为 `npm.cmd run check`。

浏览器人工步骤：开始→四件物资→南门撤离→再次开局；另检查窗口缩放、背包丢弃拾回、失焦暂停、两页同时打开，以及正式构建资源加载。性能、截图和具体通过范围见 `docs/campus-3d-verification.md`。

后续顺序：精修南门样板→扩相邻区块→少量敌人与战斗→夜景和照明→手机操作与性能分级。上下楼、坡地和跳跃需要另行加入三维物理；首版不把这类能力当作已实现。
